# Task 1: Add Booking Amount to Schema

**Priority**: CRITICAL
**Status**: ✅ COMPLETE
**Dependencies**: None

## Objective

Add a configurable `bookingAmount` field to the `Tenant` model for storing the minimum required booking/advance amount.

## Changes Required

### 1. Schema Update

**File**: `backend/prisma/tenant.prisma`

Add the `bookingAmount` field:

```prisma
model Tenant {
    id                       String                @id @default(uuid()) @db.Uuid
    name                     String
    slug                     String                @unique
    status                   TenantStatus          @default(Active)
    
    // Slot generation settings
    timezone                 String                @default("Asia/Dhaka")
    weekendDays              Json                  @default("[5,6]")
    autoGenerateEnabled      Boolean               @default(false)
    autoGenerateDaysAhead    Int                   @default(14)
    
    // NEW: Booking amount configuration
    bookingAmount            Decimal?              @db.Decimal(10, 2)
    
    // ... rest of existing fields
    
    @@index([status])
    @@map("tenants")
}
```

### 2. Apply Schema Changes

**Commands**:
```bash
cd backend
npx prisma db push
npx prisma generate
```

### 3. Verification

- Verify field appears in generated Prisma client
- No breaking changes (field is nullable)
- Can query tenant with bookingAmount
- Can update tenant with bookingAmount

## Notes

- Field is nullable (`Decimal?`) to allow:
  - Existing tenants without a booking amount (backward compatible)
  - Optional configuration (tenants who don't want this feature)
- Default decimal precision (10, 2) is sufficient for BDT amounts
- No migration needed — using `db push` for schema-first approach
